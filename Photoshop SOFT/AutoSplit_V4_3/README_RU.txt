AutoSplit V4.1 — Photoshop 2026, Windows, один запуск из Photoshop

ПЕРВЫЙ ЗАПУСК
1. Распакуйте все файлы в одну папку. Не запускайте JSX прямо из ZIP.
2. Нужен установленный Python 3 с библиотеками Pillow, numpy, opencv-python.
   Если использовали предыдущую AutoSplit Universal и она уже делила PNG, Python, вероятно, настроен.
   Иначе установите библиотеки в командной строке:
      py -3 -m pip install -r requirements.txt
3. Откройте в Photoshop исходный набор с ПРОЗРАЧНЫМ фоном (RGB).
4. Файл -> Сценарии -> Обзор -> AUTOSPLIT_ONE_CLICK_V4.jsx.
5. После обработки откроется НОВЫЙ документ со слоями. Сохраните его в PSD.

Что происходит автоматически:
- Photoshop экспортирует временную PNG-копию открытого документа.
- Windows запускает локальный Python-анализатор, который делит объекты.
- Photoshop импортирует PNG в новый документ, каждый на свой слой.
- Исходный документ не перезаписывается.

Дополнительно объекты PNG лежат во временном каталоге Windows:
%TEMP%\AutoSplit_Photoshop_2026\run_...\output\objects_cropped
Полноразмерные PNG лежат в папке layers_full_canvas того же каталога.
Временные файлы автоматически НЕ удаляются.

Ограничения:
- Нужен Windows и доступ к запуску локального .bat / Python.
- Это одна команда в Photoshop, но Python остаётся необходимым для распознавания объектов.
- Соприкасающиеся изображения могут определиться как один объект.
- Отдельные маленькие детали автоматически прикрепляются к ближайшему объекту.
- Нельзя гарантировать качество разделения на любом произвольном наборе.
- Не закрывайте Photoshop во время обработки.
- При ошибке посмотрите worker.log в указанной папке run_... .

Эта версия подготовлена и проверена на уровне Python. Запуск в реальном Photoshop 2026 не проверен.

ИСПРАВЛЕНИЕ V4.1
Photoshop может сохранять скрытые RGB-значения в полностью прозрачных пикселях PNG.
Ранее проверка сравнивала даже невидимые RGB и ошибочно прекращала обработку.
Теперь проверяется прозрачность всех пикселей и цвет каждого видимого пикселя.
Если действительно потеряны видимые пиксели, обработка по-прежнему останавливается.
